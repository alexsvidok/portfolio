# Правила проекта: сайт-портфолио

Стек: React + Vite + Tailwind CSS + Framer Motion + Lucide React.
Требования ниже обязательны для всех дальнейших задач.

## 1. Язык
- Язык интерфейса и всех текстов сайта: русский.

## 2. Типографика
- Ни при каких обстоятельствах не использовать длинное тире (—).
- Везде ставить только среднее тире «–» с пробелами по краям.

## 3. Интерактивные уточнения
- Если в задаче есть хотя бы малейшая неоднозначность (выбор анимации, расположение блока, обрезка фото, формат отображения видео), не придумывать самостоятельно.
- Остановиться и задать пользователю короткий структурированный список вопросов с вариантами ответа (А / Б / В).

## 4. Эстетика
- Стиль Apple: минимализм, много воздуха.
- Мягкий эффект матового стекла Liquid Glass / backdrop-blur.
- Плавные микро-анимации.
- Идеальный адаптив под iPhone и десктоп.

## 5. Шрифты
- Интерфейс и основной текст: Inter (чистый гротеск, полная поддержка кириллицы), с запасным стеком `-apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui, sans-serif`.
- Акцентные заголовки и крупные цифры: Playfair Display (выразительная антиква с полной кириллицей). Альтернатива для геометрии: Manrope.
- Подключать через `@fontsource` или Google Fonts с подмножеством `cyrillic`.

## 6. Материалы
- Исходники пользователя лежат в `content_input/` (photos, cases_media, video_links.md, extra_notes.md). Перед сборкой читать их.
